Hyperspectral Food Analysis 教學 Demo

用公開 SpectroFood 資料集示範 VIS-NIR hyperspectral 光譜資料分析：先用 Python 建立可重現流程，再用 Orange Data Mining 做視覺化機器學習。

1. 教學目標

認識資料 食品/農產品樣本的光譜 band 很多，每個 band 可視為一個特徵。
Python Demo 建立下載、整理、視覺化、建模與評估的完整可重現流程。
Orange Demo 用拖拉式 workflow 解釋特徵、target、模型與評估。

2. 使用資料集

本教材使用 SpectroFood dataset。資料包含 apple、broccoli、leek、mushroom 的 VIS-NIR hyperspectral measurements，並提供 dry matter content，可用於食品品質預測。

欄位類型 在本教材中的用途
光譜 band 模型特徵，整理後命名為 wl_*
dry matter 回歸目標 dry_matter_pct
crop / sample 資訊 分類目標或 metadata
如果要教「高光譜影像 cube 的 pixel 分類」，可另接 Indian Pines、Salinas-A、Pavia University 這類遙測資料；本教材先聚焦食品光譜與 Orange 最容易上手的表格格式。

4. Python 教學講解

核心問題 A：可以用光譜預測 dry matter 嗎？

用 dry_matter_pct 當 target，wl_* 當 features。範例中比較 PLS Regression 與 Random Forest Regression。

模型 教學重點
PLS Regression 光譜 band 高度相關，PLS 可用 latent components 同時做降維與回歸。
Random Forest Regression 非線性 baseline，能產生 band importance，方便討論哪些波段重要。

核心問題 B：可以用光譜辨識 crop 嗎？

用 crop 當 target，模型輸出 accuracy 與 confusion matrix。這個 demo 很適合初學者理解分類模型。

核心問題 C：模型真的能泛化嗎？

程式另外輸出 leave_one_crop_out_regression.csv，每次留下一種 crop 當測試集。這比隨機切分更能提醒學生：高分不一定代表能套用到新作物或新批次。

5. Orange Data Mining Demo

先用 Python 整理出 Orange 可讀的 `.tab` 檔，再用 Orange 建立 workflow。

Orange 檔案

檔案 目標
data/processed/spectrofood_regression_orange.tab 回歸：預測 dry_matter_pct
data/processed/spectrofood_classification_orange.tab 分類：預測 crop

Demo A：乾物率回歸

File → Data Table → Select Columns → Preprocess → PLS / Random Forest → Test and Score → Predictions
  1. 在 File 載入 spectrofood_regression_orange.tab。
  2. 確認 wl_* 是 features，dry_matter_pct 是 target，sample_id 與 crop 是 meta。
  3. 加上 Preprocess，建議做 standardization。
  4. 加入 PLS 與 Random Forest。
  5. 用 Test and Score 選 5-fold cross validation，觀察 RMSE、MAE、R2。

Demo B：作物分類

File → PCA → Scatter Plot → Random Forest / SVM → Test and Score → Confusion Matrix
  1. 在 File 載入 spectrofood_classification_orange.tab。
  2. 用 PCA 與 Scatter Plot 看不同 crop 是否分群。
  3. 加入 Random Forest 或 SVM。
  4. 用 Test and Score 比較模型，再用 Confusion Matrix 看錯分情形。
Orange-Spectroscopy add-on 可補充 Spectra、Preprocess Spectra、PLS 等 widget。若學生剛開始學，先用本教材的表格版流程會更順。

6. 課堂活動建議

  1. 先讓學生看 mean spectra，猜哪些 crop 光譜差異最大。
  2. 用 PCA scatter plot 討論「視覺分群」與「模型分類」的差別。
  3. 比較 PLS 與 Random Forest 的 dry matter 預測結果。
  4. 把 random split 改成 leave-one-crop-out，討論為什麼泛化能力下降。
  5. 在 Orange 中重建相同分析，讓學生理解 workflow 與 Python 程式是同一件事的兩種表達方式。
