Hyperspectral Food Analysis 教學 Demo

用公開 SpectroFood 資料集示範 VIS-NIR hyperspectral 光譜資料分析：先用 Python 建立可重現流程，再用 Orange Data Mining 做視覺化機器學習。

1. 教學目標

認識資料食品/農產品樣本的光譜 band 很多，每個 band 可視為一個特徵。
Python Demo建立下載、整理、視覺化、建模與評估的完整可重現流程。
Orange Demo用拖拉式 workflow 解釋特徵、target、模型與評估。

2. 使用資料集

本教材使用 SpectroFood dataset。資料包含 apple、broccoli、leek、mushroom 的 VIS-NIR hyperspectral measurements，並提供 dry matter content，可用於食品品質預測。

欄位類型在本教材中的用途
光譜 band模型特徵，整理後直接用實際波長命名，例如 397.66、400.28、402.9
dry matter回歸目標 dry_matter_pct
crop分類目標，class 應為 leek、apple、broccoli、mushroom

3. Python 操作流程

最簡單的方式是在課程資料夾執行：

cd D:\course\food_analysis
.\run_demo.ps1

若想逐步教學，可分段執行：

python scripts\01_download_spectrofood.py
python scripts\02_prepare_spectrofood.py
python scripts\04_fix_orange_crop_labels.py
python scripts\05_rename_wavelength_columns.py
python scripts\03_python_teaching_demo.py
Download→Prepare table→Repair labels→Rename wavelengths→Modeling

4. Orange Data Mining Demo

先用 Python 整理出 Orange 可讀的 `.tab` 檔，再用 Orange 建立 workflow。

檔案目標
data/processed/spectrofood_regression_orange.tab回歸：預測 dry_matter_pct
data/processed/spectrofood_classification_orange.tab分類：預測 crop
若 class 是 l1、l2、l3 這類樣本代碼，請執行 .\fix_orange_crop_labels.ps1。
若欄位名稱是 wl_397_66，請執行 .\fix_wavelength_column_names.ps1。修正後欄位會顯示 397.66、400.28、402.9。

乾物率回歸

File→Select Columns→Preprocess→PLS / Random Forest→Test and Score

Features 選實際波長欄位，例如 397.66、400.28；Target 選 dry_matter_pct。

作物分類

File→PCA→Scatter Plot→Random Forest / SVM→Confusion Matrix

Features 選實際波長欄位；Target 選 crop，其值應為 leek、apple、broccoli、mushroom。
